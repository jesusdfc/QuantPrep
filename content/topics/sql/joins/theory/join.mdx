# Joins & Row Multiplication

A join clause in the Structured Query Language (SQL) combines columns from one or more tables
into a new table. The operation corresponds to a join operation in relational algebra.
Informally, a join stitches two tables and puts on the same row records with matching fields.
There are several variants of `JOIN`: `INNER`, `LEFT OUTER`, `RIGHT OUTER`, `FULL OUTER`,
`CROSS`, and others.

As a special case, a table (base table, view, or joined table) can `JOIN` to itself in a
self-join. A programmer writes a `JOIN` predicate to identify the records for joining. If the
evaluated predicate is true, the combined record is then produced in the expected format, a
record set or a temporary table.
